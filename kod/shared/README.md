# kod/shared

Contracts that every package uses. Owner: the SPEC (kod/SPEC.md). Builders do not edit these; they propose changes in SPEC §24 Builder notes.

- `brand.json` – the ONE place of the product name (`name`). Everything else reads it.
- `src/enums.ts` – domain enums and UI labels (SPEC §5–§6, §17.2).
- `src/api.ts` – API request/response types (SPEC §12).
- `demo/fixtures.json` – fictional demo data: NAV invoices for the three demo clients, manual revenue, expected tax results as of 2026-11-17 (SPEC §7.6, §19). Generated by a script; regenerate together with SPEC §7.6, never by hand.
- `scripts/sync-shared.mjs` – copies the above into a consumer: `node ../shared/scripts/sync-shared.mjs src/_shared` (run on predev/prebuild).

Check: `npx -p typescript@5.9.3 tsc -p tsconfig.json`
